## Exam Format & Scoring (Per the Official Exam Guide)

| Item | Detail |
|---|---|
| Exam code | **DVA-C03** (registration opens **December 1, 2026**; the last day to take DVA-C02 is **November 30, 2026**) |
| Question types | **Multiple choice** (1 correct, 3 distractors) and **multiple response** (2 or more correct out of 5 or more options; **all** correct answers required for credit) |
| Questions | **65 total: 50 scored + 15 unscored** (unscored items are not identified) |
| Guessing | No penalty. Unanswered questions score as incorrect, so always answer |
| Scoring | Scaled **100 to 1,000**; **minimum passing score 720**; pass/fail designation |
| Scoring model | **Compensatory:** you do not need to pass each domain, only the overall exam |
| Target candidate | **1+ years** of hands-on experience developing and maintaining AWS applications |

> The exam guide does not list the exam duration or price. Confirm both on the AWS Certification site when you register.

## What Changed From DVA-C02 to DVA-C03

| Area | Change |
|---|---|
| **Domain weights** | Development 32% to **30%**; Security 26% (unchanged); Deployment 24% to **Testing and Deployment 22%**; Troubleshooting and Optimization 18% to **22%** |
| **New Task 2.3** | Five skills on securing AI services: access, data privacy, input/output filtering, agent security, protecting logs (**Module 10**) |
| **AI in development** | AI-assisted dev tools (**Kiro**) and managed AI services (**Amazon Bedrock**, **Bedrock AgentCore**, **Amazon Quick**) |
| **AI across domains** | AI tools for generating tests (3.2.5), CI/CD support (3.3.9), error analysis (4.1.5), and optimization (4.3.6) |
| **Other additions** | Presigned URLs (S3 and CloudFront), container image build and management with ECR, container orchestration deployments (ECS, EKS, Fargate) |
| **Moved** | Unit testing with SAM to Domain 3; Lambda performance tuning to Domain 4; serialization to Task 1.1; API Gateway stages and custom domains to Task 3.1 |
| **Consolidated** | DynamoDB (4 skills to 1), security (13 to 7), testing (11 to 5), observability (8 to 5), optimization (9 to 6). The guide states these do **not** reduce emphasis |
| **Out of scope (explicit)** | Designing architectures, designing CI/CD pipelines, administering IAM users and groups, selecting FMs / prompt engineering / designing RAG, AI safety framework design, ETL pipelines, networking design |

**Services the guide lists as out of scope** include Amazon Polly, Amazon Rekognition, Amazon SageMaker AI, Strands Agents, AWS Shield, AWS Transfer Family, Storage Gateway, Snow Family, and Amazon Connect. Do not spend study time on them.

## Recommended 5-Week Study Plan (~40 Hours)

| Week | Modules | Hands-On Lab |
|---|---|---|
| 1 | 01, 02, 03 | Build an API Gateway + Lambda + DynamoDB app with `sam deploy`; add request validation and a canary alias |
| 2 | 04, 05, 06 | SQS + SNS fan-out with DLQ and redrive; DynamoDB with a GSI, TTL, and Streams trigger; S3 lifecycle rule |
| 3 | 07, 08, 09, 10 | Cognito user pool + identity pool with per-user S3 prefix; KMS envelope encryption; Secrets Manager rotation; Bedrock call with a Guardrail |
| 4 | 11, 12, 13 | Push a container to ECR with a lifecycle policy; CodePipeline with CodeBuild and CodeDeploy canary to Lambda; ECS Fargate service with circuit breaker |
| 5 | 14, 15, 16 | X-Ray tracing, EMF metrics, and alarms; Logs Insights queries; DAX or ElastiCache in front of a table; Lambda Power Tuning |

**Final week tips:** re-read each module's *Common Exam Traps* section, redo the self-assessment checks, and practice multiple-response questions (all correct options are required). Compare services on **limits, defaults, and which one is the managed shortcut**, since distractors usually offer custom code where a native feature exists.
